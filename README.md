# 🚀 КосмоДром — Solar System Explorer

Интерактивная 3D-игра для юных исследователей космоса на **Three.js**. Это не статическая демонстрация: ребёнок управляет камерой, выбирает цель полёта, запускает автоматическую экскурсию и узнаёт короткие факты о планетах.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:4173`. Для проверки интерфейса:

```bash
npx playwright install chromium
npm test
```

> Three.js загружается через import map с unpkg, поэтому для первого запуска нужен доступ к сети.

## Управление

- **ЛКМ / касание** — вращать камеру вокруг цели;
- **ПКМ** — перемещать камеру;
- **колесо** — приблизить или отдалить;
- **название планеты справа или подпись в космосе** — плавно полететь к объекту;
- **Экскурсия** — автоматически посетить Солнце и планеты;
- **Домой** — вернуться к общему виду;
- кнопки `0.2×`, `1×`, `10×` и «Пауза» управляют игровым временем.

## Архитектура

- `main.js` запускает приложение;
- `scene.js`, `renderer.js`, `camera.js`, `controls.js` собирают техническую сцену;
- `world.js` создаёт звёзды, Солнце, восемь планет и орбиты;
- `engine.js` обновляет игровое время, анимации, навигацию и подписи;
- `navigation.js` отвечает за перелёты, домашний вид и экскурсию;
- `labels.js` проецирует позиции 3D-объектов в интерактивные HTML-подписи;
- `ui.js` связывает игровое состояние с панелями управления;
- `updatables.js` хранит объекты общего игрового цикла.

Движение вычисляется через абсолютное `time.elapsed`, а не накоплением угла. Пауза и изменение скорости поэтому одинаково влияют на орбиты, вращение планет и мерцание звёзд. У каждой звезды есть собственные атрибуты `phase` и `speed`, поэтому мерцание не синхронно.

## Следующий план улучшений

1. **Луна и спутники.** Вложенная орбита Луны вокруг движущейся Земли, затем главные спутники планет-гигантов.
2. **Текстуры и материалы.** Оптимизированные текстуры планет, нормали, облака Земли и кольца Сатурна с учётом слабых устройств.
3. **Живое Солнце.** Многослойное свечение, корона и анимированная поверхность без потери FPS.
4. **Игровой прогресс.** Отмечать посещённые миры, выдавать значки и сохранять достижения локально.
5. **Мини-задания.** Викторины после экскурсии, поиск планет по подсказкам и коллекция карточек-фактов.
6. **Улучшенная экскурсия.** Озвучка, субтитры, управление длительностью остановки и кнопки «назад/дальше».
7. **Доступность.** Полная клавиатурная навигация, режим повышенного контраста и настройка уменьшения движения.
8. **Космические события.** Пояс астероидов, кометы и редкие визуальные события.
9. **Производительность.** Автоматические профили качества, instancing и визуальные regression-тесты для desktop/mobile.
10. **PWA.** Офлайн-кэш ресурсов и установка приложения на планшет.
