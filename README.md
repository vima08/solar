# 🚀 КосмоДром — Solar System Explorer

Браузерное космическое приключение на **Three.js** с доступным управлением. Управляйте кораблём, исследуйте планеты и луны, выполняйте экспедиционные миссии и первый оплачиваемый контракт. Проект развивается в сторону торговли, текстовых квестов и открытий.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:4173`. Для проверки интерфейса:

```bash
npx playwright install chromium
npm test
```

> Three.js загружается через import map из `node_modules`, поэтому перед запуском выполните `npm install`. Workflow GitHub Pages устанавливает и публикует эту зависимость автоматически; сайт доступен по пути `/solar/`.

## Управление

Первый оплачиваемый рейс находится в **Журнале**: Земля → Марс, 1 место груза и 100 кредитов награды. Контрактный круиз занимает 5 минут активного времени; пауза и скрытая вкладка его останавливают. Рынки и расходование кредитов появятся в следующих срезах.

На планшете доступны два аналоговых стика: левый управляет тягой и поворотом, правый — тангажом и креном. Закройте пульт для ручного управления. Включить стики вручную можно в настройках. **Настройки → Сохранение и загрузка** позволяют скачать JSON и восстановить рейс из файла после подтверждения.

Пошаговый [сценарий игры и проверки на планшете](specs/001-first-contract/playtest.md) описывает полный рейс и перенос сохранения.

- **ЛКМ / касание** — вращать камеру вокруг цели;
- **ПКМ** — перемещать камеру;
- **колесо** — приблизить или отдалить;
- **Пульт → Маршрут** — выбрать планету или спутник для обзора и полёта;
- **На корабль → К цели** — включить автопилот к выбранному объекту; повторное нажатие останавливает переход;
- **Посадка** — доступна в радиусе 8 игровых единиц от поверхности планеты или луны. Корабль остаётся на ней, движется вместе с ней и сохраняет место посадки;
- на газовых и ледяных гигантах корабль садится на исследовательскую платформу;
- **Взлёт** — подняться над поверхностью и продолжить полёт;
- **W/S**, **A/D**, **↑/↓**, **←/→** — тяга, поворот, тангаж и крен;
- **Пульт → Миссии** — доставить зонд на Марс, собрать образец на Европе и вернуть его на Землю. Задачи выполняются посадкой; кнопка «Показать цель» выбирает маршрут;
- **Пульт → Корабль** — приборы, вид из кабины, простой режим и заправка после посадки на Землю;
- **Пульт → Настройки** — громкость сайфай-мелодии и двигателя, экскурсия, викторина и время (`0.04×`, `0.2×`, `2×`, «Пауза»);
- стрелки всегда зарезервированы за тангажом и креном корабля, даже при фокусе на вкладке или ползунке пульта;
- **Alt+1…4** — вкладки пульта, **Alt+P** — открыть/закрыть пульт, **Esc** — закрыть. На телефоне пульт открывается кнопкой внизу экрана.

## Архитектура

Инструкции для участников находятся в [AGENTS.md](AGENTS.md). Игровое направление описано в [docs/game-vision.md](docs/game-vision.md), процесс работы со спецификациями и независимой оценкой — в [docs/development-workflow.md](docs/development-workflow.md). [Первый игровой срез](specs/001-first-contract/spec.md) реализован и ожидает игры владельца.

JavaScript-модули разнесены по слоям, чтобы входная точка оставалась тонкой, а ответственность файлов была видна по пути:

- `js/main.js` — точка входа: ждёт `DOMContentLoaded`, собирает сцену, UI, экспедицию и запускает игровой цикл;
- `js/app/` — инфраструктура Three.js и браузера: `scene.js` создаёт приложение, `renderer.js`, `camera.js`, `controls.js` и `resize.js` настраивают рендер, камеру, OrbitControls и адаптацию к окну;
- `js/core/` — общая механика: `engine.js` ведёт цикл `requestAnimationFrame`, `time.js` хранит игровое время/скорость/паузу, `updatables.js` управляет объектами общего цикла, `constants.js` содержит масштабы, цвета и данные планет;
- `js/world/` — содержимое космоса: `world.js` наполняет сцену звёздами, Солнцем, планетами, орбитами, поясом астероидов и кометой; `planet.js`, `planets.js`, `sun.js`, `stars.js`, `asteroids.js`, `comet.js` отвечают за отдельные тела и эффекты;
- `js/world/planet-textures.js` — процедурные карты поверхностей без внешних файлов: материки Земли, полосы и Большое красное пятно Юпитера, кратеры и атмосферные узоры остальных планет;
- `js/ui/` — пользовательский слой: `ui.js` связывает DOM-панели с игровым состоянием, `navigation.js` отвечает за перелёты, домашний вид и экскурсию, `labels.js` проецирует 3D-позиции в интерактивные HTML-подписи, `expedition.js` ведёт корабль, миссии и прогресс;
- `js/assets/` — `scifi-music.js` создаёт оригинальную мелодическую сайфай-тему с арпеджио, басом и мягкой перкуссией средствами Web Audio; `audio-resources.js` содержит звуки двигателя и столкновения;
- `service-worker.js` кэширует app shell и обновлённые пути модулей для PWA-режима.

Поток данных остаётся однонаправленным: `main.js` создаёт `world`, UI добавляет навигацию и экспедицию, а `core/engine.js` каждый кадр обновляет время, все updatable-объекты, навигацию, подписи и рендер. Движение вычисляется через абсолютное `time.elapsed`, а не накоплением угла. Пауза и изменение скорости поэтому одинаково влияют на орбиты, вращение планет и мерцание звёзд. У каждой звезды есть собственные атрибуты `phase` и `speed`, поэтому мерцание не синхронно.
