# Проект **Solar System Explorer** — текущее состояние (после последнего этапа)

## Общая идея

Создается интерактивная 3D-модель Солнечной системы на **Three.js**.

Цель проекта — не просто демонстрация планет, а небольшое игровое приложение с красивой графикой, плавной архитектурой и возможностью дальнейшего развития.

Основной принцип разработки:

> Сначала строим качественную архитектуру движка, затем постепенно добавляем визуальные эффекты и игровые возможности.

# Архитектура движка

На данный момент приложение уже разделено на независимые подсистемы.

```
main.js
      │
      ▼
engine.js
      │
      ▼
scene.js
      │
      ▼
world.js
      │
 ┌────┴───────────────┐
 │                    │
 ▼                    ▼
Stars              Solar System
```

Главная идея:

- **main.js** — точка входа.
- **engine.js** — игровой цикл.
- **scene.js** — создаёт технические объекты Three.js.
- **world.js** — наполняет сцену космическими объектами.

Это разделение считается удачным и дальше меняться не должно.

# planet.js

Создан универсальный конструктор любой планеты.

Очень важное архитектурное решение.

Планета имеет структуру:

```
Planet Group

    Orbit Group

        Sphere
```

Именно Orbit Group вращается вокруг Солнца.

Sphere просто находится на расстоянии distance.

Таким образом позже можно без изменений добавить:

```
Atmosphere

Clouds

Labels

Moons

Rings
```

---

Также в planet.js реализован

```
update(time, delta)
```

где

```
orbit.rotation.y =
time.elapsed * orbitSpeed
```

То есть используется абсолютное игровое время.

Это исключает накопление ошибок и автоматически поддерживает изменение скорости времени.

# Что принципиально решили в архитектуре

Было принято важное решение:

Все движения будут вычисляться через

```
time.elapsed
```

а не через накопление углов.

То есть вместо

```
angle += speed * delta
```

используется

```
angle = elapsed * speed
```

Преимущества:

- нет накопления ошибки;
- изменение скорости времени работает автоматически;
- пауза работает автоматически;
- проще вычислять положение любого объекта.

Эта концепция останется основной для всего проекта.

# Долгосрочный план

После реализации управления временем развитие проекта предполагается в таком порядке:

1. Полностью интегрировать UI управления временем.
2. Перевести мерцание звёзд на игровое время и сделать его независимым для каждой звезды (`phase` + `speed`).
3. Добавить орбитальные линии.
4. Добавить вращение планет вокруг своей оси.
5. Добавить Луну и показать вложенную систему орбит (Луна вокруг Земли).
6. Постепенно заменить цветные сферы текстурами.
7. Начать визуальное усложнение Солнца (свечение, корона, затем шейдер и анимация плазмы).

На текущем этапе фундамент архитектуры можно считать сформированным: игровой цикл, система времени, модульная структура и модель космических объектов уже позволяют развивать проект без необходимости крупных рефакторингов.
