## Требуемые минимальные исправления

1. **Средняя серьёзность, противоречивая приёмка F2.** Уточнить формулировку: v и b меняют рассчитанную относительную траекторию/метрики; u меняет только скорости относительно станции, сохраняя относительную траекторию. Сейчас F2 одновременно требует невозможного для выбранной модели и противоречит шагу2. Зафиксировать браузерную/численную проверку неизменности точек при смене только u. Это уточнение уже описанной модели, не расширение её объёма.

2. **Средняя серьёзность, неполный проверяемый контракт F3.** В шаге2 явно отделить UI b=1,2..6 от тестового API с 1,2≤|b|≤6, чтобы предусмотренный spec тест зеркала был выполним. В шаге5 определить измеряемый порог сходимости: например, для безопасных пресетов h=0,02 против h=0,01 относительное изменение ближайшего расстояния и выходных скоростей <0,1%, угла поворота <0,1°. Сравнивать при одинаковом начальном/конечном радиусе и одинаковом физическом горизонте, не только одинаковом числе шагов. Текущие max8000 дают40с при h=0,005 вместо160с при h=0,02: это допустимый incomplete, но не доказательство сходимости выхода. Сохранить исходный порог энергии/момента <0,1%, не заменять им проверку сходимости.

## Замечания для реализации без изменения объёма

- На низком v энергия может быть близка к нулю: определить ненулевую нормировку относительной ошибки энергии; контролировать ошибку по всей безопасной траектории, включая перицентр, а не только на выходе. Для заявленного UI диапазона полезна численная сетка безопасных параметров, не только четыре пресета.
- Метрика closest approach по сегментам — дискретное приближение; аналитическое пересечение отрезка защищает от туннелирования, но не даёт точного касания истинной кривой. Проверить пограничный случай при h/2 и не заявлять реальную орбитальную точность.
- Не сбрасывать только clock при global pause, одновременно продолжая playback: условие движения должно учитывать getTime().paused и document.hidden. То же относится к закрытой вкладке/пульту, если решено останавливать её проигрывание.
- Имеющийся корабль на поверхности перемещается вместе с планетой даже без действий пользователя; для F6 зафиксировать инертное состояние в режиме выбора объекта либо сравнивать относительное положение/сохраняемое состояние с учётом естественного движения.
