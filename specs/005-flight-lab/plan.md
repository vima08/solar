Статус: awaiting-owner-playtest. Локальная поставка готова; независимая техническая приёмка PASS. Публикация не выполнялась. Независимый план READY. Реализация после независимого READY; владелец разрешил пройти оба локальных среза без промежуточного ручного ревью.

1. `game/flyby.js`: чистый двумерный velocity-Verlet для ускорения -μr/|r|³. Номинальный h=0,02, максимум8000 шагов (160 условных секунд), без зависимости от FPS. После замечания независимого критика F3 каждый номинальный шаг разбит на4 фиксированных подшага Verlet: максимум32000 подшагов, до8001 выводимых точек; горизонт сохранён. Это уменьшает ошибку безопасного низкоскоростного пролёта без изменения критериев. Завершить при выходе на начальный радиус после перицентра либо при контакте с R=1; пересечение отрезком поверхности проверять аналитически, включая касание. Вычислять closest approach по отрезкам; конечные равные радиусы интерполировать на выходе, скорости интерполировать по шагу с контролем погрешности. Сохранять энергию/момент и максимальные ошибки для численных тестов. Точки траектории с time, position, velocity; ограничить число выводимых точек≤8001. Без сторонней физической зависимости.
2. Валидация конечных чисел и ограничений: параметры UI как вspec; чистая функция дополнительно допускает b=-6..6 (в том числе0 для прямого удара) для численной проверки зеркала; тестовый μ0..1, h0,005..0,04 и1..8000 шагов. Ни один неподходящий ввод не вызывает бесконечный цикл/NaN. Статусы escaped/collision/incomplete; метрики выхода только escaped. Серый курс — начальное прямолинейное движение на тот же горизонт. Скорости станции считаются прибавлением постоянного вектора планеты, преобразование систем не изменяет динамику относительной траектории; изменение u не изменяет нарисованную относительную траекторию.
3. `ui/flight-lab.js`: новая шестая вкладка «Курс»/Alt6 (существующие Alt1–5 сохранить), ползунки с подписями и4 пресета. Canvas автоматически масштабирует обе линии и планету, выводит легенду/точку; вычисления по input, не покадрово. Один рисунок/анимация из рассчитанных точек, rAF управляет только временем проигрывания. Play/pause/reset, visibilitychange и общая пауза сбрасывают frame-clock; изменение параметров ставит на начало. Параметры/анимация живут в UI без записи в saveStore или storage.

UI объясняет, что реальный корабль/автопилот не меняются; условная модель и системы скоростей названы. Для незавершённого расчёта не давать ложный итог.
