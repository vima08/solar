## Модель и сохранения (Q3–Q6)

Career3 добавляет `discovery: { stage, choice }`. Stage: unheard → signal → choice → return → completed. Choice=null до return; дальше open либо salvage. Отличный от unheard этап требует completed исходного контракта. `discovery-state.js` задаёт значения/валидацию без импорта переходов, `discovery.js` реализует чистые переходы и тексты. Contracts нормализует career1/2 в3 с unheard, сохраняя рынок/деньги. Текущий career3 требует корректное поле discovery; повреждения блокируют запись с исходной копией, файловый импорт отклоняется. Файл3 принимает1/2 через миграцию; карьера3 защищает от перезаписи старыми сборками. Один прежний localStorage key сохраняется.

Переходы: listen (completed контракт, любое место), survey (signal+Европа), open (choice+Европа,+40), salvage (choice+Европа, свободное место), finish (return+порт по ветке,+30/110). Каждое действие содержит expectedStage; данные перечитываются при исполнении. Проверять безопасную арифметику до изменения состояния. Конечный completed исключает повторную выплату. Подтверждение хранит исходный stage; при изменении места/issue переход повторно проверяется. Экономика и этап пишутся вместе через существующий `store.commit`, а не через предварительную мутацию. Сбой записи оставляет карьеру прежней.

Общий usedSpace +=1 только для return/salvage. Этот счётчик уже используется рынками, исходным и курьерским контрактами. Регистратор не включать в marketCargo и не продавать; исторические образцы не менять. Сброс вызывает newCareer, respawn сохраняет всю карьеру. Барьеры другой вкладки действуют для всех переходов.

При переходе на Career3 обязательно заменить жёсткую проверку version===2 в обоих переходах `markets.js` на общую текущую версию из contracts; иначе остановятся торговля и подработка. Включить discovery (или usedSpace) в ключ кеша `ui/markets.js`: взятие регистратора не меняет деньги/marketCargo, но должно сразу обновить занятость и доступность покупки. Ключ UI контрактов уже включает usedSpace. Адаптировать ожидаемый формат экспорта в тестах рынков с2 на3, сохранив отдельные реальные фикстуры v1/v2. Проверить на браузерном UI: один товар + регистратор =2; покупка отключена сразу, после сдачи снова доступна; курьерская подработка на Career3 по-прежнему работает.

## Интерфейс и мир (Q1/Q2/Q7)

Карточка приключения первой в «Миссиях» после завершения контракта, прежний onboarding сохраняется. Индикатор на существующей кнопке журнала сообщает о новой истории без новой перекрывающей плашки. Сцены — несколько коротких абзацев, явный прогресс/следующий шаг, отдельная кнопка маршрута использует chooseDestination. Ветка выбирается кнопкой → нативный dialog с условиями → отдельное подтверждение, которое не превращается во вторую кнопку после первого клика; повторная кнопка блокируется. Тексты из кода через textContent; журнал выводится из stage/choice, не из сохранённого HTML.

Небольшой `discovery-beacon.js`: два светящихся кольца вокруг Европы, привязанные к существующему телу, без влияния на физику/камеру. Видимость только signal/choice/return. Render UI кешировать по изменяемым полям, не пересоздавать DOM покадрово. Добавить модули в app-shell и поднять версию кэша. Не добавлять шестую вкладку или нижнюю кнопку.
